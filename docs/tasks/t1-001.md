# t1-001: 28 GHz inset-fed patch on RO4350B

Tier 1 (element). The agent submits an antenna-cad `DesignSpec` (center
frequency, feed impedance, laminate thickness, polarization). The evaluator
synthesizes the patch, inset feed, and board with antenna-cad 0.2 and scores
the synthesized geometry. Agents never submit coordinates.

Requirements (`tasks/t1-001-patch-28ghz-ro4350b/task.yaml`):

| id | metric | limit |
|---|---|---|
| s11-in-band | `s11_max_in_band_db` | <= -10 dB over 27.5-28.5 GHz |
| footprint | `footprint_mm` | <= 6 mm |
| f-res-lo / f-res-hi | `f_res_ghz` | 27.5 to 28.5 GHz |

## Deviation from the task brief: laminate thickness is a choice

The brief fixed the laminate at 0.254 mm. On that laminate the task cannot
be solved: the best design found in a search over synthesis target and feed
impedance reaches -8.6 dB worst-case in band (80 ohm feed). The cavity
model puts the total Q of a 28 GHz patch on 0.254 mm RO4350B at about 26,
which allows roughly 630-790 MHz of -10 dB bandwidth against the 1 GHz
asked for. Even with surface-wave loss added, which this model omits and
which lowers Q, the estimate stays under 1 GHz.

So the task keeps every number in the brief (eps_r 3.66, tan_delta 0.0037,
the band, -10 dB, 6 mm) and lets the agent pick the thickness from the
RO4350B stock list, with 0.254 mm stated as the board shop's default. That
turns the bandwidth problem into a design trade, because antenna-cad's board
margin grows with thickness (max(6h, lambda0/4) on each side) and the feed
line runs through that margin:

| h (mm) | best worst-case in-band \|S11\| (dB) | footprint (mm) |
|---|---|---|
| 0.254 | -8.6 | 5.3 |
| 0.338 | -10.3 | 5.2 |
| 0.422 | -11.8 | 5.1 |
| 0.508 | -13.1 | 5.5 |
| 0.762 | -16.9 (29.4 GHz target, 50 ohm) | 6.8 (fails) |

Values come from `reference/solve.py` (verbose output) and the trap tests.

## What the evaluator computes

`src/aedl/evaluators/patch_element.py` validates the spec (RO4350B only, a
stock thickness, linear polarization, no array section, no keys outside the
DesignSpec fields), checks that antenna-cad's material table agrees with the
task's eps_r and tan_delta (a disagreement raises instead of picking one),
synthesizes the patch, and reads the dimensions back from the synthesized
design: patch width and length, inset depth, feed width, and the feed length
from the board-edge port to the inset point.

At the `analytic` tier those dimensions go into the cavity model in
`src/aedl/evaluators/patch_cavity.py`, which is implemented in AEDL and does
not import antenna-cad:

- static eps_eff and Z0: Hammerstad and Jensen (1980);
- eps_eff dispersion: Kirschning and Jansen (1982);
- open-end extension: Hammerstad, `dL = 0.412 h (eps_eff + 0.3)(W/h + 0.264) / ((eps_eff - 0.258)(W/h + 0.8))`;
- resonance: `f = c / (2 (L + 2 dL) sqrt(eps_eff(f)))`, iterated because
  eps_eff depends on f;
- slot conductances G1 and G12: Balanis eqs. 14-12 and 14-18a;
- `Q_rad = w eps0 eps_r W L / (4 h (G1 + G12))`, `Q_c = h sqrt(pi f mu0 sigma)`,
  `Q_d = 1 / tan_delta`, combined in parallel;
- inset resistance `R_edge cos^4(pi y0 / L)` with
  `R_edge = (Q_t / Q_rad) / (2 (G1 + G12))` (cos^4 is the notched-inset
  correction of Basilio et al., 2001);
- `Z_patch = R_in / (1 + j Q_t (f/f_r - f_r/f))`, carried to the port along a
  lossless line of the feed's impedance and dispersive phase constant, and
  compared with the 50 ohm system impedance.

The claimed center frequency never enters the model. The synthesis target
sets the dimensions, and the resonance is computed from those dimensions.
For the reference the two differ by 3.6 % (28.67 GHz target, 27.65 GHz
resonance), which is the dispersion pre-compensation the task asks for.

`tests/test_patch_cavity.py` checks the closed forms against worked examples:
Balanis 14.3 (G1 = 1.57 mS, edge resistance 228.3 ohm), Balanis 14.1
(dL = 0.081 cm, 10 GHz resonance), and Pozar 3.7 (50 ohm at W/d = 3.081,
eps_eff 1.87).

## Accuracy band, and what a pass means

The analytic tier cannot certify band coverage, and its results say so:
`info["fidelity"]` is `analytic` and `info["certifies_band_coverage"]` is
false.

- Resonance: about +/-3 %. The static and dispersive eps_eff treatments
  alone differ by 3.3 % for the reference patch on 0.508 mm, and the
  transmission-line and cavity models are usually quoted within a few percent
  of measurement on thin substrates. 3 % of 28 GHz is 840 MHz, close to the
  whole band.
- Bandwidth: low by up to about 25 %. The model omits surface-wave loss
  (the Jackson-Alexopoulos estimate puts it at 15 % of the power on
  0.254 mm and 26 % on 0.508 mm) and feed-line radiation, both of which lower
  Q. Neglected feed reactance moves the match locus by an amount the model
  does not estimate.
- Match depth: the cos^4 inset taper is empirical, so R_in carries its own
  error, which shows up directly in |S11|.

The evaluator reports the in-band worst case with the resonance moved by
-3, -1, +1 and +3 % (`info["uncertainty"]`). For the reference those are
-5.6, -9.6, -9.8 and -6.0 dB against -13.1 dB nominal: its 3.1 dB of nominal
margin does not survive a 1 % resonance error.

A margin requirement wide enough to cover the uncertainty band would make
the task infeasible: covering +/-1 % alone needs about 1.56 GHz of -10 dB
bandwidth, more than any stock thickness inside the footprint provides
under this model. The task therefore keeps the brief's -10 dB threshold
and labels the result instead of gating on a margin. The `openems` tier
(`evaluator.params.fidelity: openems`) is the rung that can certify. It runs
the same synthesized board through antenna-cad's openEMS backend when
openEMS is installed natively or as the `antenna-cad-openems` Docker image,
and otherwise raises an error naming what is missing. It is a nightly tier
and is not part of the default test run (`requires_openems` marker).

## Calibration: each requirement catches a specific wrong design

| design | h (mm) | Z (ohm) | target (GHz) | f_res (GHz) | worst in-band (dB) | footprint (mm) | fails |
|---|---|---|---|---|---|---|---|
| textbook | 0.254 | 50 | 28.00 | 27.44 | -2.7 | 5.38 | s11, f-res-lo |
| thin, re-centred | 0.254 | 70 | 28.55 | 27.97 | -8.2 | 5.28 | s11 |
| thick | 0.762 | 50 | 29.40 | 28.01 | -16.9 | 6.83 | footprint |
| no dispersion pre-compensation | 0.508 | 60 | 28.00 | 27.02 | -5.5 | 5.61 | s11, f-res-lo |
| overshoot | 0.508 | 60 | 30.50 | 29.37 | -3.8 | 5.37 | s11, f-res-hi |
| reference | 0.508 | 70 | 28.67 | 27.65 | -13.1 | 5.54 | none |

The tests in `tests/test_t1_001.py` pin each row. The reference resonance
sits 150 MHz above the lower band edge while the |S11| minimum is at
28.01 GHz: the 70 ohm feed line rotates the over-coupled patch impedance
toward 50 ohm above resonance. `f_res` is the cavity's TM010 resonance, not
the frequency of best match.

## Known limits

- Only inset feeds: antenna-cad 0.2's DesignSpec has no feed-type field, so
  the probe-fed variant in the brief is not offered.
- The footprint counts the feed line to the board edge, which antenna-cad
  places max(6h, lambda0/4) from the patch. A different synthesis margin
  would change which thicknesses fit.
- The design space is three continuous-ish choices (target frequency, feed
  impedance, thickness from a list). That is deliberate: the agent chooses
  intent and the synthesizer owns the geometry. What the task measures is
  whether an agent finds the thickness trade and the dispersion offset.
